# Freelance Hub · Frontend

**La interfaz del proyecto full-stack Freelance Hub**, desarrollada con React y Vite. Este repositorio se complementa con la [API de Freelance Hub](https://github.com/G1LB3T0/Proyecto_Freelance_BackEnd), construida con Node.js, Express, Prisma y PostgreSQL.

## Documentación principal

- **Interfaz y aplicación:** [`Freelance/`](Freelance/).
- **Scripts y dependencias:** [`Freelance/package.json`](Freelance/package.json).
- **Servicio backend y endpoints:** [README de la API](https://github.com/G1LB3T0/Proyecto_Freelance_BackEnd#readme).
- **Configuración de contenedores:** [`Docker-compose.yml`](Docker-compose.yml).

## Stack

React · Vite · React Router · i18next · Chart.js · FullCalendar

El proyecto incluye scripts para Vitest, cobertura, ESLint y compilación. Consulta `package.json` para ver las herramientas y dependencias declaradas.

## Ejecutar el frontend

Con Node.js y npm instalados:

```bash
git clone https://github.com/G1LB3T0/Proyecto_Freelance_FrontEnd.git
cd Proyecto_Freelance_FrontEnd/Freelance
npm install
npm run dev
```

Abre la dirección local que Vite muestre en la terminal. Para los flujos que consumen datos, configura y ejecuta también el backend siguiendo su README.

## Comandos disponibles

Ejecuta estos comandos dentro de `Freelance/`:

| Comando | Propósito |
| :--- | :--- |
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Compilación del frontend |
| `npm run preview` | Vista previa de la compilación |
| `npm run lint` | Revisión estática con ESLint |
| `npm run test:run` | Ejecutar las pruebas configuradas |
| `npm run test:coverage` | Generar el reporte de cobertura |
